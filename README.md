# QA Automation Project - Playwright

Automation testing project developed using Playwright and TypeScript.

# Technologies 

- Visual Studio Code
- Playwright
- Git
- GitHub
- Node.js
- TypeScript

# Test Coverage
- Successful login with valid credentials
- Failed login with invalid credentials
- Failed login with empty username and password

## Project Structure

- `pages/`: Contains the Page Objects and the interaction logic for each page.
- `tests/`: Contains the automated test cases and scenarios.
- `playwright.config.ts`: Contains the general configuration for Playwright test execution.
